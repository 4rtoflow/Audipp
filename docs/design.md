# UIの基準

現在の初期画面は、明るいニュートラル色とシンプルな文字・区切り線で構成します。

- 背景：`#F6F8F7`、本文：黒、区切り線：`#E5E5E5`。
- 書体はシステム標準、文字サイズはMaterial 3のTypographyを使います。日本語の可読性を優先します。
- 初期画面の要素間隔は15 dp、左右余白は22 dp、上下余白は33 dpを基準にします。
- システムバーのinsetsを考慮し、小さい画面や大きな文字でもスクロールできるようにします。
- 未実装の機能を操作可能に見せるUIは置きません。

初期画面の参照元：[teenage engineering / Refero Styles](https://styles.refero.design/style/aecf9dda-5cba-4dc7-9e73-59b65d895cdf)。中立色と余白の考え方を参考にし、ブランド資産や独自フォントは使っていません。
